# 開発タスク一覧・詳細 要件案

## 1. 文書情報

| 項目 | 内容 |
|---|---|
| 対象 | 取引管理システムへの開発タスク参照機能の追加 |
| 状態 | 依頼に基づく要件。参照機能はサンプルデータで実装済み |
| 根拠 | 開発タスク一覧・詳細についての依頼 |
| 関連資料 | [基本設計案](../3.基本設計/development-task-basic-design.md)、[既存Webアプリ要件案](vue-springboot-external-api-requirements.html) |

## 2. 目的・範囲

開発タスクを一覧から選択し、各工程の情報をタブで参照できるようにする。タブの内容は必要になったときに取得し、詳細画面を離れるまで再利用する。

本案の対象は一覧・詳細の参照と画面遷移である。タスクやタブ内容の登録・編集・削除、検索・絞り込み、並び替え、ページングは依頼にないため本案の対象外とする。実装ではDBが空の場合にサンプルデータを投入する。実データの登録・更新方法は未決定。

## 3. 利用者・前提

- 既存アプリのホームから利用する。既存アプリはセッション認証を使用する。
- 現行実装ではログイン済みのUSER・ADMINが閲覧できる。タスク単位の権限は設けていない。
- データ取得元はアプリ内DBとし、外部サービス連携は行わない。

## 4. 機能要件

| ID | 要件 | 区分 |
|---|---|---|
| DT-R01 | ホームから開発タスク一覧へ遷移できるボタンを設ける。 | 依頼 |
| DT-R02 | 開発タスクの情報を一覧形式で表示する。 | 依頼 |
| DT-R03 | 一覧で選択した行に対応する開発タスクの詳細へ遷移する。 | 依頼 |
| DT-R04 | 詳細に「要件」「基本」「詳細」「実装」「残タスク」の5タブを設ける。 | 依頼 |
| DT-R05 | 詳細画面に遷移したときは、最初に「要件」タブを表示する。 | 依頼 |
| DT-R06 | タブ表示時、対応するタスク・タブの情報がストアにない場合はAPIから取得しストアに保持する。 | 依頼 |
| DT-R07 | 対応する情報がストアにある場合はAPIを呼ばずに表示する。 | 依頼 |
| DT-R08 | タブ用ストア値は詳細画面から離れたとき、またはログアウト時に破棄する。 | 依頼 |
| DT-R09 | 取得中、対象データなし、取得失敗を利用者が判別できる。失敗時は再試行できる場合に導線を表示する。 | 暫定案 |
| DT-R10 | 一覧へ戻る操作を設ける。 | 暫定案 |

## 5. 非機能・制約

- 認証・APIエラーは既存アプリの方式に合わせる。401ではセッション切れとしてログイン画面へ遷移する。
- タブの保持データはブラウザ内の一時的なストアとし、永続化しない暫定案とする。詳細表示中の外部更新は、破棄後に再取得するまで反映されない。
- 詳細表示中にタスクIDが変わる場合も、以前のタスクの情報を表示しない。
- 性能目標、データ量、可用性、監査対象は未指定であり、確定していない。

## 6. 未決事項

1. 実データの登録・更新・運用方法。
2. 一覧の正式な項目・状態の定義、各タブの内容と情報構造。「残タスク」の粒度・状態管理。現行はテキスト表示。
3. タスク単位のアクセス制限の要否。
4. 一覧の件数・検索・ページング、保持中に最新化する必要性。
5. データの機密性、参照操作の監査、性能・運用要件。

具体的な表示項目やAPIの現行仕様は[基本設計](../3.基本設計/development-task-basic-design.md)を参照する。
