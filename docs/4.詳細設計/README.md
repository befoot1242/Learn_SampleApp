# 詳細設計

詳細設計は、技術領域ごとの設計資料と画面別設計資料で構成する。各資料は現行実装に基づく仕様、要件案との差分、未確認事項を区別する。

| 資料群 | 内容 |
|---|---|
| [技術詳細設計一覧](details/README.md) | API、DB、認証・認可、外部API、主要処理フロー、トランザクション |
| [画面別詳細設計一覧](screens/README.md) | 各画面の項目、入力、操作、遷移、API、表示状態 |

システム全体の概要は[基本設計書](../3.基本設計/basic-design.md)を参照する。画面キャプチャとワイヤーフレームは[その他資料の画像](../9.その他資料/images/)に格納する。
