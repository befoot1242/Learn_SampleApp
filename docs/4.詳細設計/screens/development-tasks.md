# S-09 / S-10 開発タスク一覧・詳細 画面詳細設計

## 1. 概要

| 項目 | 一覧 | 詳細 |
|---|---|---|
| パス | `/development-tasks` | `/development-tasks/:id` |
| 利用条件 | ログイン済みUSER・ADMIN | 同左 |
| 目的 | タスクを一覧から選択 | 5タブで工程の情報を参照 |

ホームの「開発タスク一覧」カードから一覧に移動する。共通レイアウト・ログアウトを使用する。検索・編集・ページングはない。[画面イメージ](../../9.その他資料/images/development-task-wireframes.svg)は設計時の例であり、実画面キャプチャではない。

## 2. 一覧

初期表示時に一覧APIを呼ぶ。タスクID、タスク名、状態、更新日を表示する。行のクリックまたはタスク名リンクから該当IDの詳細へ遷移する。リンクはキーボードからも操作できる。取得中、0件、取得失敗は別々に表示し、再試行可能なエラーにはボタンを表示する。

## 3. 詳細

画面にはタスクID、タブ、選択タブの本文、一覧へ戻るリンクを表示する。初期タブは要件。タブは要件、基本、詳細、実装、残タスクの順。クリックまたは左右矢印・Home・Endで選択でき、選択中のタブと本文をARIA属性で関連付ける。

初回選択のタブをAPIから取得し、取得済みタブへ戻るとストアの内容を表示する。取得中は読み込み表示、`null` または空文字は情報なし、失敗時はメッセージと再試行可能な場合のみ再試行ボタンを表示する。本文は改行を保持したテキストで表示し、HTMLとして解釈しない。

一覧へ戻る、他画面へ移動、別IDへ移動、ログアウトまたはセッション切れで保持内容は破棄される。APIは[技術詳細設計](../details/development-task-design.md)、ストアの取得・破棄条件は[ストア状態管理詳細設計](../details/store-usage-report.md)を参照する。
