# 入力形式・文字種分類

## 1. 目的

画面設計書における入力項目の文字種・入力形式を、共通の分類IDで記載する。本書で分類を定義し、画面別設計書は入力項目ごとの分類IDと固有の長さ・必須・範囲制約を記載する。

`C-00`は文字種を制限しない入力であり、「制約未定義」ではない。画面固有の検証実装がある場合は、画面別設計書に併記する。

## 2. 分類一覧

| ID | 分類 | 許可文字・形式 | 主な適用項目 |
|---|---|---|---|
| C-00 | 任意文字列 | 文字種の制限なし。画面固有の長さ・必須制約のみ適用 | 表示名、取引先、備考、検索キーワード |
| C-01 | 半角ASCII印字可能文字 | U+0020–U+007E | 社員コード |
| C-02 | 共通テキスト | C-01、U+3000–U+30FF、U+4E00–U+9FFF、U+FF01–U+FF60、U+FF61–U+FF9F、U+FFE0–U+FFEE。改行不可 | 氏名、住所 |
| C-03 | 共通複数行テキスト | C-02にCR・LFを加えた範囲 | 自由記入欄 |
| C-04 | ユーザID | 半角英字・数字・`_`・`.`・`-`（`[a-zA-Z0-9_.-]+`） | ユーザ管理のユーザID |
| C-05 | メールアドレス | メールアドレス形式 | メールアドレス |
| C-06 | URL | `http://`または`https://`で始まるURL形式 | WebサイトURL |
| C-07 | 電話番号 | `0`で始まる数字。ハイフンは任意 | 電話番号 |
| C-08 | 郵便番号 | 数字3桁、任意のハイフン、数字4桁 | 郵便番号 |
| C-09 | 全角カタカナ | 全角カタカナ、長音、半角/全角空白 | 氏名（カナ） |
| C-10 | 半角英字氏名 | 半角英字、空白、`.`、`'`、`-` | 英字氏名 |
| C-11 | 社員番号 | 半角英大文字・数字6〜12文字（`[A-Z0-9]{6,12}`） | 各種申請の社員番号 |
| C-12 | 日付 | `YYYY-MM-DD`形式の実在日付 | 日付、利用期間 |
| C-13 | 時刻 | HTML `time`形式 | 開始時刻、終了時刻 |
| C-14 | 日時 | HTML `datetime-local`形式 | 通知希望日時 |
| C-15 | 整数 | HTML numberで受け付ける整数。画面固有の最小・最大値を適用 | 数量、評価 |
| C-16 | 金額 | HTML numberで受け付ける正の数値。画面固有の小数可否・下限を適用 | 金額 |
| C-17 | 割合 | HTML numberで受け付ける整数。0〜100の範囲を適用 | 割合 |
| C-18 | 選択値 | セレクトまたはラジオで定義済みの選択肢のみ | ロール、状態、性別、機密区分 |
| C-19 | 複数選択値 | チェックボックスで定義済みの選択肢を1件以上選択 | 利用言語 |
| C-20 | カラーコード | HTML colorが返す`#RRGGBB`形式 | テーマカラー |
| C-21 | ファイル名 | ブラウザで選択したファイルの名前。ファイル本体は保存しない | 添付ファイル |
| C-22 | 真偽値 | チェックボックスで指定するtrueまたはfalse | 利用規約同意、メール配信希望 |

## 3. 記載ルール

- テキスト、パスワード、email、tel、url、date、time、datetime-local、number、range、color、file、select、radio、checkboxなど、ユーザが値を指定するUIには分類を記載する。
- 表示専用の項目、ボタン、画面遷移パラメータには分類を記載しない。
- 複数の分類が関係する場合は、値の形式を表す分類を優先し、範囲・文字数は画面別設計書に併記する。
- C-01〜C-22の分類にそぐわない値は、対応する画面で項目別バリデーションエラーとして表示する。画面固有のフォーカスアウト時の検証対象・エラー文言は各画面設計書に記載する。
