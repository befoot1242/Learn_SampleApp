## 2. 画面項目・入力値

| 項目 | UI | 必須 | 初期値 | 文字種 | 入力値・制約 |
|---|---|---|---|---|---|
| 社員コード | テキスト入力 | 必須 | 空文字 | 半角ASCII（U+0020–U+007E） | 前後の空白を除去して検証。文字数上限なし |
| 氏名 | テキスト入力 | 必須 | 空文字 | 共通テキスト文字種ホワイトリスト | 前後の空白を除去し、100文字以内 |
| 住所 | テキスト入力 | 必須 | 空文字 | 共通テキスト文字種ホワイトリスト | 前後の空白を除去し、200文字以内 |
| 日付 | 日付入力 | 必須 | 空文字 | 数字・ハイフン | 実在する日付。`YYYY-MM-DD` 形式 |
| 自由記入欄 | 複数行テキスト | 任意 | 空文字 | 共通テキスト文字種ホワイトリスト、改行 | 1000文字以内 |

### 共通テキスト文字種ホワイトリスト

氏名、住所、自由記入欄では、次の文字範囲を許可する。範囲外の文字（絵文字など）は入力エラーとする。自由記入欄に限り、改行（CR、LF）も許可する。

| 種別 | Unicode範囲 | 例 |
|---|---|---|
| 半角ASCII | U+0020–U+007E | `A`, `1`, `!` |
| 日本語文字・句読点 | U+3000–U+30FF | `　`, `あ`, `ア`, `。` |
| CJK統合漢字 | U+4E00–U+9FFF | `漢`, `字` |
| 全角英数字・記号 | U+FF01–U+FF60、U+FFE0–U+FFEE | `Ａ`, `１`, `！` |
| 半角カタカナ・記号 | U+FF61–U+FF9F | `ｱ`, `｡` |

## 3. 操作

| 操作 | 処理 |
|---|---|
| フォーカスアウト | フォーカスを外した項目を検証し、エラーがあれば項目の下に表示する。再度フォーカスアウトした時に再検証し、解消していればエラーを消す |
| 入力値変更 | 表示中の受付完了メッセージを消す |
| 送信 | 全項目を検証する。エラーがなければ受付完了メッセージを表示する |
| クリア | 全入力値、項目エラー、受付完了状態を初期化する |

送信後の入力内容は保存されない。このサンプル画面では受付完了メッセージのみを表示する。

## 4. 入力チェック・表示状態

- 必須項目が未入力、または空白文字のみの場合は項目ごとにエラーを表示する。
- 氏名が100文字、住所が200文字、自由記入欄が1000文字を超える場合は項目エラーを表示する。
- 日付は形式に加えて実在する日付かを検証する。
- 社員コードに半角ASCII文字以外が含まれる場合は項目エラーを表示する。
- 氏名、住所、自由記入欄は上記ホワイトリストに基づいて全角・半角を検証し、文字幅の変換は行わない。
- フォーカスアウト時は対象項目のみを検証する。未フォーカスアウトの項目は送信時に検証する。
- 入力エラーがある場合、受付完了メッセージは表示しない。
- 送信が有効な場合、「入力を受け付けました。このサンプル画面ではデータは保存されません。」と表示する。
