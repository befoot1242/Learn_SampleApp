## 2. 画面項目・入力値

| 項目 | UI | 必須 | 初期値 | 入力形式分類 | 入力値・制約 |
|---|---|---|---|---|---|
| 社員コード | テキスト入力 | 必須 | 空文字 | [C-01](input-character-types.md#2-分類一覧) | 前後の空白を除去して検証。文字数上限なし |
| 氏名 | テキスト入力 | 必須 | 空文字 | [C-02](input-character-types.md#2-分類一覧) | 前後の空白を除去し、100文字以内 |
| 住所 | テキスト入力 | 必須 | 空文字 | [C-02](input-character-types.md#2-分類一覧) | 前後の空白を除去し、200文字以内 |
| 日付 | 日付入力 | 必須 | 空文字 | [C-12](input-character-types.md#2-分類一覧) | 実在する日付 |
| 自由記入欄 | 複数行テキスト | 任意 | 空文字 | [C-03](input-character-types.md#2-分類一覧) | 1000文字以内 |

分類の許可文字範囲は[入力形式・文字種分類](input-character-types.md)を参照する。

## 3. 操作

| 操作 | 処理 |
|---|---|
| フォーカスアウト | フォーカスを外した項目を検証し、エラーがあれば項目の下に表示する。再度フォーカスアウトした時に再検証し、解消していればエラーを消す |
| 入力値変更 | 表示中の受付完了メッセージを消す |
| 送信 | 全項目を検証する。エラーがなければ受付完了メッセージを表示する |
| クリア | 全入力値、項目エラー、受付完了状態を初期化する |

送信後の入力内容は保存されない。このサンプル画面では受付完了メッセージのみを表示する。

## 4. 入力チェック・表示状態

- 必須項目が未入力、または空白文字のみの場合は項目ごとにエラーを表示する。
- 氏名が100文字、住所が200文字、自由記入欄が1000文字を超える場合は項目エラーを表示する。
- 日付は形式に加えて実在する日付かを検証する。
- 社員コードに半角ASCII文字以外が含まれる場合は項目エラーを表示する。
- 氏名、住所、自由記入欄はC-02/C-03に基づいて検証し、文字幅の変換は行わない。
- フォーカスアウト時は対象項目のみを検証する。未フォーカスアウトの項目は送信時に検証する。
- 入力エラーがある場合、受付完了メッセージは表示しない。
- 送信が有効な場合、「入力を受け付けました。このサンプル画面ではデータは保存されません。」と表示する。

### 4.1 フォーカスアウト時の項目別検証

各入力項目の`blur`イベントで、対象項目だけを検証する。検証エラーは対象項目の直下に表示し、再度フォーカスを外した時に検証を通過すれば消去する。

| 項目 | フォーカスアウト時の検証 | エラーメッセージ |
|---|---|---|
| 社員コード | 必須。前後の空白を除いて評価し、半角ASCII（U+0020–U+007E）以外を含まないこと | 未入力: 「社員コードを入力してください」<br>文字種不正: 「社員コードは半角ASCII文字で入力してください」 |
| 氏名 | 必須。前後の空白を除いて評価し、100文字以内かつ共通テキスト文字種ホワイトリストの範囲内であること | 未入力: 「氏名を入力してください」<br>文字数超過: 「氏名は100文字以内で入力してください」<br>文字種不正: 「氏名に使用できない文字が含まれています」 |
| 住所 | 必須。前後の空白を除いて評価し、200文字以内かつ共通テキスト文字種ホワイトリストの範囲内であること | 未入力: 「住所を入力してください」<br>文字数超過: 「住所は200文字以内で入力してください」<br>文字種不正: 「住所に使用できない文字が含まれています」 |
| 日付 | 必須。`YYYY-MM-DD`形式であり、実在する日付であること | 未入力: 「日付を入力してください」<br>形式または日付不正: 「有効な日付を入力してください」 |
| 自由記入欄 | 任意。1000文字以内であり、改行を含む共通テキスト文字種ホワイトリストの範囲内であること | 文字数超過: 「自由記入欄は1000文字以内で入力してください」<br>文字種不正: 「自由記入欄に使用できない文字が含まれています」 |

前後空白を除去する変換結果は、フォーカスアウト時の検証にだけ使用する。画面の入力値への書き戻しは、全項目の送信時検証が成功した場合に行う。
