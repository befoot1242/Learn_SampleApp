# 既存資料カバレッジ

## 評価の前提

この一覧は、2026-10-25時点でリポジトリに存在する資料の記載内容を、「[設計書に記載すべき内容](../1.前提資料/2.設計書に記載すべき内容.md)」に照らして確認したものである。資料の文章に何が書かれているかを評価し、実装の正しさ・動作・テスト済みであることは保証しない。工程間の対応と不足は、[要件・設計・実装トレーサビリティ](要件設計実装トレーサビリティ.md)（2026-10-31照合）を参照する。

| 評価 | 意味 |
|---|---|
| 充足 | 資料種別として定めた対象範囲の主要項目が記載されている。 |
| 一部 | 概要や一部の項目は記載されているが、未定義・未確認・対象範囲の不足が残る。 |
| 未記載 | 現存資料内で記載を確認できない。 |
| 対象外 | 開発案内または図版等の補助資料であり、設計内容を記載する資料ではない。 |
