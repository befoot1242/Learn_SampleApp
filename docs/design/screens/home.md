# S-02 ホーム画面 詳細設計

## 1. 画面概要

| 項目 | 内容 |
|---|---|
| 画面ID | S-02 |
| 画面名 | ホーム |
| URL | `/` |
| 認証 | 必須 |
| 利用ロール | USER、ADMIN |
| コンポーネント | `frontend/src/views/HomeView.vue` |
| 共通枠 | `AppLayout` |

![ADMINのホーム画面](../images/home-admin.png)

![USERのホーム画面](../images/home-user.png)

## 2. 画面項目

| 項目 | UI | 表示・操作仕様 |
|---|---|---|
| 画面タイトル | 見出し | 「ホーム」 |
| 挨拶 | テキスト | Auth Storeの表示名を用いて挨拶を表示 |
| 取引一覧 | メニューカード | クリックで `/transactions` へ遷移 |
| 取引登録 | メニューカード | クリックで `/transactions/entry` へ遷移 |
| ユーザ管理 | メニューカード | ADMINのみ表示。クリックで `/users` へ遷移 |

共通ヘッダーにはアプリ名、表示名、ロール、ログアウト操作を表示する。共通サイドメニューにはホーム、取引一覧、取引登録を表示し、ユーザ管理はADMINに限り表示する。

## 3. ロール別表示

| 機能 | USER | ADMIN |
|---|---|---|
| 取引一覧カード・メニュー | 表示 | 表示 |
| 取引登録カード・メニュー | 表示 | 表示 |
| ユーザ管理カード・メニュー | 非表示 | 表示 |

ユーザ管理URLへの直接アクセスもRouterガードで制御する。USERの場合はホームへ戻る。

## 4. 操作・遷移

| 操作 | 結果 |
|---|---|
| 取引一覧カードまたはメニュー | 取引一覧へ遷移 |
| 取引登録カードまたはメニュー | 取引登録へ遷移 |
| ユーザ管理カードまたはメニュー（ADMIN） | ユーザ管理へ遷移 |
| ログアウト | `POST /api/auth/logout` 後、ログイン画面へ遷移 |

## 5. 表示状態・API

- ホーム画面自身はAPIを呼び出さない。
- RouterガードがAuth Storeを初期化し、ユーザ情報を取得した後に表示する。
- 初期化できたユーザ情報がない場合の個別エラー表示・ローディング表示は実装されていない。
- 未認証の場合は画面表示前にログイン画面へ遷移する。

## 6. 要件案との対応

要件案の「ホーム（メニュー）」からユーザ管理・取引一覧・取引入力へ遷移する構成に対応する。ユーザ管理メニューは現行実装ではADMINに限定される。
