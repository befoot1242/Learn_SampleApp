## 2. 検索条件

| 項目 | UI | 条件・動作 |
|---|---|---|
| キーワード | テキスト入力 | ユーザID・表示名・メールの部分一致。空欄は条件なし |
| ロール | セレクト | すべて、ADMIN、USER |
| 状態 | セレクト | すべて、ACTIVE（有効）、DISABLED（無効） |
| 検索 | ボタン | 現在の条件で検索。検索中は無効化 |
| 新規登録 | ボタン | 新規登録モードを開く。入力値・メッセージを初期化 |

画面表示時に検索APIを呼び出す。キーワードはサービス側で前後空白を除去する。

## 3. 一覧

| 列 | 内容 |
|---|---|
| ユーザID | ログインID |
| 表示名 | ユーザ表示名 |
| メール | メールアドレス |
| ロール | ADMINを「管理者」、USERを「一般」と表示 |
| 状態 | ACTIVEを「有効」、DISABLEDを「無効」と表示 |
| 操作 | 編集。ACTIVEかつログイン中ユーザ本人以外には無効化も表示 |

検索結果が0件の場合「該当するユーザがいません」と表示する。編集対象の行は選択状態として表示する。

## 4. 登録・編集領域

一覧と同一画面内に表示する。登録・編集の開始時に成功/エラーメッセージと項目エラーを初期化する。

| 項目 | 新規登録 | 編集 | UI・制約 |
|---|---|---|---|
| ユーザID | 入力 | 表示・変更不可 | 必須、最大50文字、半角英数字と `_ . -` のみ |
| 表示名 | 入力 | 入力 | 必須、最大100文字 |
| メールアドレス | 入力 | 入力 | 必須、メール形式、最大255文字 |
| ロール | USER初期値、選択可 | 現在値、選択可 | USERまたはADMIN |
| 状態 | 新規作成時ACTIVE | 編集時に選択可 | ACTIVEまたはDISABLED |
| 初期パスワード | 入力 | 表示しない | 新規時必須、8〜72文字。パスワード入力 |
| 保存 | 作成API | 更新API | 成功後、編集領域を閉じて一覧を再検索 |
| キャンセル | 入力を閉じる | 入力を閉じる | 一覧データは変更しない |

### ロール変更履歴

編集モードで対象ユーザの履歴を取得する。履歴が1件以上ある場合、変更日時、変更前ロール、変更後ロール、変更者を表示する。初回作成時の変更前ロールは「(新規)」と表示する。履歴取得が失敗した場合、画面は空配列として扱い、履歴取得専用のエラー表示は行わない。

## 5. 操作・API

| 操作 | API | 成功後の動作 |
|---|---|---|
| 初期表示・検索 | `GET /api/users?keyword&role&status` | 一覧を更新 |
| 新規保存 | `POST /api/users` | 成功メッセージ表示、編集領域を閉じ、一覧を再検索 |
| 編集開始 | `GET /api/users/{id}/role-history` | 編集値とロール履歴を表示 |
| 更新保存 | `PUT /api/users/{id}` | 成功メッセージ表示、編集領域を閉じ、一覧を再検索 |
| 無効化 | `POST /api/users/{id}/disable` | 確認後に無効化し、成功メッセージと一覧を更新 |

新規登録要求は `username`, `displayName`, `email`, `role`, `password`。更新要求は `displayName`, `email`, `role`, `status`。ユーザID重複は `DUPLICATE_USER` エラーとなる。

無効化はブラウザ標準の確認ダイアログを表示してから実行する。本人の無効化ボタンは表示しない。バックエンドも本人無効化を拒否する。

## 6. 表示状態・エラー

- 一覧の検索中はローディング状態を保持し、検索ボタンを無効化する。
- 成功時は画面上部に成功メッセージを表示する。
- APIの項目別エラーは該当項目の下に表示し、その他はエラー領域に表示する。
- HTTP 401を受けた場合はセッション期限切れとしてログイン画面へ遷移する。
- ADMIN以外の直接アクセスはRouterでホームへ戻される。APIもADMIN以外を拒否する。

## 7. 要件案との差分

要件案は外部IdP認証を前提とし、パスワードを自前保持しないとしている。現行実装ではユーザを自システムで作成し、初期パスワードを受け取ってBCryptハッシュを保存する。ロール・状態の管理、検索、登録、編集、無効化、ロール履歴参照は画面に実装されている。
