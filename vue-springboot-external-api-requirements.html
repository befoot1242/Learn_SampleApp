1. システム概要と前提

  • フロントエンドは Vue 3 + TypeScript
  • バックエンドは Spring Boot
  • 外部APIを対向システムとして利用
  • 画面は SPA、API は BFF 経由で接続

主要コンポーネント

  • Web UI / 認証API / ユーザ管理API
  • 取引参照API / 取引登録API / DB

3. 認証・認可要件

認証方式

  • OAuth2 Authorization Code + PKCE
  • トークン管理はバックエンドで実施
  • セッションは HttpOnly Cookie で保持

認可方式

  • ロール: 管理者 / 一般ユーザ
  • 画面・APIにロールベース制御を適用
  • 監査ログにログイン/操作結果を記録

4. ユーザ管理機能要件

管理対象（自前テーブル）

  • ユーザID / 表示名 / メール / 状態

6. 取引登録機能メニュー要件

取引入力画面

  • 必須項目チェックとフォーマット検証
  • 確認ダイアログ後に登録APIを実行
  • 成功時は受付番号と結果を表示
  • 失敗時は入力保持+エラー理由を表示

外部API登録時の方針

  • 重複送信防止のリクエストID付与
  • タイムアウト時は状態照会導線を提供

7. API連携・非機能要件

外部API連携

  • Spring Bootで接続先を一元管理
  • 接続タイムアウト、再試行回数を定義
  • 外部エラーを業務エラーへ正規化

非機能

  • 可用性: 外部API障害時の縮退運転
  • 性能: 一覧2秒以内（95パーセンタイル）
  • 監査: 認証と取引操作ログを保管
  • セキュリティ: CSRF/XSS/SQLi対策を適用

9. 画面遷移案

基本遷移

  • ログイン → ホーム（メニュー）
  • ホーム → ユーザ管理
  • ホーム → 取引一覧 → 取引詳細
  • ホーム → 取引入力 → 登録結果

エラー時遷移

  • 認証エラー時はログインへ戻す
  • 外部API障害時は同画面で再試行表示
  • 登録失敗時は取引入力へ戻し再編集

遷移制御はVue Router + ガードで実装
